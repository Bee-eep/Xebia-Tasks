APP SCENARIO
You have been handed the codebase of an Employee Attendance Tracker — a Python application used by an HR team to manage employee records, track attendance, calculate working hours, and generate monthly reports. The application fetches employee data from a REST API, stores attendance records in a SQL database, and processes daily check-in/check-out times. A junior developer wrote the initial version but introduced several bugs. Your job is to find and fix them all.

BUG 01 · api_client.py 2 bugs
Fetching Employee Records from the HR API
The function below is responsible for fetching an employee's details from the internal HR API. It is returning errors and occasionally crashing.
import requests API_BASE_URL = "https://hr-internal.company.com/api" def get_employee(employee_id): url = f"{API_BASE_URL}/employees/{employee_id}" response = requests.get(url) ← Bug A data = response.json() return data["employee"] ← Bug B
Symptoms
A — Requests to the API are being rejected with a 401 Unauthorized error. The API requires an Authorization header with a bearer token stored in a constant API_TOKEN.

B — When the API returns a 404 (employee not found), the function crashes with a KeyError instead of returning None gracefully.
Your tasks
  1. Add the missing Authorization header to the request.
  2. Handle the case where the employee is not found — return None instead of crashing.

Querying Attendance Records from the Database
The function below queries attendance records for a specific employee in a given month. It is returning incorrect data and in some cases returning records for all employees.
def get_monthly_attendance(conn, employee_id, month, year): query = """ SELECT a.date, a.check_in, a.check_out, e.name FROM attendance a LEFT JOIN employees e ← Bug A ON a.employee_id = e.id WHERE a.month = ? ← Bug B AND a.year = ? ORDER BY a.date ASC """ cursor = conn.cursor() cursor.execute(query, (month, year)) return cursor.fetchall()
Symptoms
A — Records are returned even when there is no matching employee in the employees table. Only attendance records with a valid, existing employee should be returned.

B — The query is returning attendance records for all employees in that month, not just the specified one. The employee_id filter is never applied.
Your tasks
  1. Change the JOIN type so only records with a matching employee are returned.
  2. Add the missing employee_id filter to the WHERE clause and pass it correctly to the query.

BUG 03 · attendance.py 2 bugs
Calculating Working Hours for the Day
This function calculates the number of hours an employee worked in a day and flags them as late if they checked in after 9:00 AM. Both calculations are producing wrong results.
from datetime import datetime WORK_START = "09:00" LATE_THRESHOLD_MINUTES = 15 def calculate_hours(check_in: str, check_out: str): fmt = "%H:%M" ci = datetime.strptime(check_in, fmt) co = datetime.strptime(check_out, fmt) duration = ci - co ← Bug A hours_worked = duration.seconds / 3600 start = datetime.strptime(WORK_START, fmt) late_by = (ci - start).seconds // 60 is_late = late_by > LATE_THRESHOLD_MINUTES ← Bug B return round(hours_worked, 2), is_late
Symptoms
A — hours_worked is always negative or producing a very large incorrect number. The subtraction operands are in the wrong order.

B — An employee who checks in exactly 15 minutes late is not being flagged, but they should be. The boundary condition is off by one.
Your tasks
  1. Fix the subtraction so duration represents time from check-in to check-out.
  2. Correct the comparison operator so an employee who is exactly 15 minutes late is also flagged.
Logic bug Off-by-one ~12 min

BUG 05 · report.py 2 bugs
Flagging Employees Below Minimum Attendance
HR policy requires that employees must be present for at least 20 days per month and must not exceed 3 late check-ins before a warning is issued. Both conditions in this function have logic errors.
MIN_DAYS_REQUIRED = 20 MAX_LATE_DAYS = 3 def check_attendance_policy(summary): days_present = summary["days_present"] late_days = summary["late_days"] below_minimum = days_present > MIN_DAYS_REQUIRED ← Bug A exceeded_late = late_days > MAX_LATE_DAYS ← Bug B if below_minimum or exceeded_late: return { "warning": True, "reason": [] + (["Below minimum attendance"] if below_minimum else []) + (["Exceeded late check-ins"] if exceeded_late else []) } return {"warning": False, "reason": []}
Symptoms
A — Employees who attend fewer than 20 days are not being flagged. Employees who attend more than 20 days are being flagged instead. The comparison is inverted.

B — An employee with exactly 3 late check-ins is not receiving a warning, but HR policy states that 3 or more late check-ins should trigger one.
Your tasks
  1. Fix the below_minimum condition so it correctly flags employees who attended fewer than the minimum required days.
  2. Fix the exceeded_late condition so employees with exactly MAX_LATE_DAYS late check-ins are also flagged.
Logic bug Off-by-one ~12 min
