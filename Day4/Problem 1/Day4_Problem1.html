Arrays

2 problems
Q1 · Arrays
Second Largest Without Duplicates
Given an integer array, find and return the second largest unique element. If no such element exists, return -1.
Input: [12, 35, 1, 10, 34, 1] Output: 34 Input: [10, 10, 10] Output: -1
Constraint: Do not use sorting. O(n) solution expected.
Easy ~10 min Linear traversal
Q2 · Arrays
Rotate Array K Steps to the Right
Given an array of integers and a number k, rotate the array to the right by k positions in-place.
Input: [1, 2, 3, 4, 5, 6, 7], k = 3 Output: [5, 6, 7, 1, 2, 3, 4] Input: [-1, -100, 3, 99], k = 2 Output: [3, 99, -1, -100]
Handle edge case: k may be larger than array length.
Medium ~12 min In-place, modulo

Strings

2 problems
Q3 · Strings
Valid Anagram Check
Write a function that takes two strings and returns true if one is an anagram of the other, false otherwise. Comparison should be case-insensitive and ignore spaces.
Input: "Listen", "Silent" Output: true Input: "hello world", "world hello" Output: true Input: "rat", "car" Output: false
Do not use any built-in sort function. Use a frequency map.
Easy ~8 min Hash map
Q4 · Strings
Longest Substring Without Repeating Characters
Given a string, find the length of the longest substring that contains no repeating characters.
Input: "abcabcbb" Output: 3 (substring: "abc") Input: "bbbbb" Output: 1 (substring: "b") Input: "pwwkew" Output: 3 (substring: "wke")
Sliding window approach expected. Brute force will receive partial credit.
Medium ~12 min Sliding window

Q5 · SQL
Top Earning Employees per Department
Given the tables below, write a query to find the name and salary of the highest-paid employee in each department. Include department name in the result.
Employees(emp_id, name, salary, dept_id) Departments(dept_id, dept_name) Expected output columns: dept_name, name, salary
Handle the case where two employees share the top salary in the same department — both should appear.
Medium ~10 min JOIN, GROUP BY
Q6 · SQL
Monthly Order Revenue Report
Using the Orders table, write a query to find the total revenue and number of orders placed each month in the year 2024, ordered from highest revenue to lowest.
Orders(order_id, customer_id, order_date, amount) Expected output columns: month, total_revenue, total_orders
Use DATE functions to extract the month. Format the month as a readable name (Jan, Feb…) if your SQL dialect supports it.
Easy–Medium ~8 min Aggregate, date functions

API Integration

2 problems
Q7 · API Integration
Fetch and Display User Posts
Using the public REST API at https://jsonplaceholder.typicode.com, write a script that:
  1. Fetches all posts for the user with userId = 3
  2. Prints the title of each post in uppercase
  3. Prints the total count of posts fetched at the end
Endpoint: GET /posts?userId=3 Expected output: TITLE OF POST ONE TITLE OF POST TWO ... Total posts: N
Handle HTTP errors gracefully — print a useful error message if the request fails.
Easy ~10 min GET, JSON parsing
Q8 · API Integration
Weather Summary with Conditional Logic
Using the Open-Meteo API (free, no API key required), fetch the current temperature and weather code for any city of your choice. Based on the weather code returned, print a human-readable weather condition.
Base URL: https://api.open-meteo.com/v1/forecast Required query parameters: latitude = {your chosen city's latitude} longitude = {your chosen city's longitude} current_weather = true Sample response (current_weather object): { "temperature": 18.2, "windspeed": 12.4, "weathercode": 3 } Weather code reference (handle at least 5): 0 → Clear sky 1 → Mainly clear 2 → Partly cloudy 3 → Overcast 45 → Fog 61 → Light rain 80 → Rain showers 95 → Thunderstorm Expected console output: City : London Temperature: 18.2°C Condition : Overcast
A hardcoded mapping table or dictionary for weather codes is perfectly acceptable.
Medium ~12 min GET, query params, conditionals
